# Boat 16

PWA для подготовки к ОГЭ по обществознанию и математике. В обычном браузере сайт показывает
только страницу установки; учиться — в установленном приложении (Safari → Файл → «Добавить в Dock»,
Chrome — кнопка установки). Без сборки и зависимостей: статические файлы, ES2017, без фреймворков.

Локально: `python3 -m http.server 8782 --directory boat16`, приложение — `http://localhost:8782/?app`
(на localhost `?app` открывает приложение в браузере, а service worker берёт файлы из сети, не из кеша).

## Путь темы

`video → notes → review → practice`, затем повторы через 3 и 7 дней (логика старого сайта):

| шаг | обществознание | математика |
|---|---|---|
| изучить | дочитать шпору, тест вариант 1 на «5», 25 мин практики | дочитать шпору, 60 мин практики |
| повтор 1 (+3 дня) | вариант 2 теста на «5» | 10 новых задач, 8 верных |
| повтор 2 (+7 дней) | вариант 3 на «5» | 10 новых задач, 8 верных |

Каждые 15 активных минут практики — по желанию опрос: 10 вопросов из закреплённых тем обоих предметов.

## Маршруты

`#/` главная · `#/t/<id>/<video|notes|review|practice>` тема · `#/materials` · `#/settings`

## Перенос прогресса

settings → импорт принимает и экспорт старого сайта «Тетрадь ОГЭ» (`oge-social`, version 2–3):
берутся темы, решённые задачи и отмеченные ошибки, остальное (XP, сезон и т. п.) игнорируется.

## Публикация

GitHub Pages из корня этой папки. После изменения файлов поднять `VERSION` в `sw.js`,
чтобы установленные приложения скачали новую версию.
